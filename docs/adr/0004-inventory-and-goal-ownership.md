# Distinguish stored items, equipment mirrors, and live goal targets

MobChat's hand slots reflect vanilla equipment. Update equipment with a separate copy when a shift-click mutates the slot stack in place. Apply placement checks to existing destination stacks as well as empty slots, because vanilla's merge path does not check the occupied destination. The main and offhand positions leave room for the mob preview and stay compatible with the client menu layout. Chested-horse inventory migration skips its physical chest slot.

Compare stacks with vanilla's item and NBT equivalence on Minecraft 1.20.1 through 1.20.4 and its item and component equivalence on later versions. Count equipment once and keep exact variants when summarizing gifts or removals. Attribute a net withdrawal from a hand to disarm before ordinary theft accounting. A stack whose object was installed as a mirror is temporary and stays out of mod inventory NBT. A conflicting stack with no mirror provenance is preserved as stored inventory. Older saves can contain an ambiguous stale mirror, so opening such a save preserves a divergent variant during the first migration.

FOLLOW, FLEE, ATTACK, LEAD, and the player protected by PROTECT follow a live player UUID from the server roster. An unavailable player pauses the goal. Resume only when that UUID resolves to a live entity in the owner's level. TALK and completed-tour callbacks stay with the originating instance so a new player entity cannot inherit stale effects. Protection clears the prior attacker when its beneficiary changes instance, because vanilla can reuse the numeric entity ID after respawn. A custom attack records its attacker so the protection goal can observe it. Preserve simulated aggression for mobs without a native attack and protect friendly players before handing control to native AI.

The inventory interception runs before the item-interaction injection. Only a vanilla interaction can count as a gift. Genuine empty-hand interaction remains distinct from consuming the last item in the hand. Social accounting runs even when a cooldown suppresses the follow-up LLM reply.

Collect matching goals before removing them so selector mutation cannot invalidate traversal. Movement speed overrides compensate for mobs whose native max-speed attributes do not fit the interaction. PROTECT raises the beneficiary's friendship to a positive value so the mob does not attack the player it was assigned to protect.
