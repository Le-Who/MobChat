# Keep game API differences in narrow version adapters

The build uses Mojang mappings and applies source replacements by increasing Minecraft version threshold. A later file replaces its earlier class by relative path. Shared rules for chat, inventory, goals, and item interactions belong outside those replacements. This keeps fixes from disappearing when the target changes and lets the compiler check real mapped signatures.

Loom packages sources through `withSourcesJar()`. The JDK that runs the compiler is configured separately from the game's runtime and the Java API release target. The historical packaging script adds a Connector marker to copies of the Fabric jar and hashes the copies after that change.

- Minecraft 1.20.5 adds Fabric payload codecs and registry-aware datagen. Keep stable mod channels and route through the version helpers. Fabric can register the same channel through common and client paths, so duplicate registration leaves the existing codec in place. Consume the receive buffer fully to avoid vanilla's extra-bytes rejection.
- Item serialization on 1.20.5 and later returns the populated tag. Store that tag so the item ID survives. Version 1.21.6 adapts entity saves to `ValueOutput` and `ValueInput`. Write slot-indexed inventory entries and accept both the older indexed wrappers and the interim flat list. The flat list stored no slot indexes, so those saves can restore only the order they contain.
- On component-era buckets, merge the `CCUUID` data into the existing bucket entity data. UUID helpers accept the earlier four-integer representation and the two-long representation for newer saves. Creaking records move through the heart's cached puppet identity where that API exists.
- Legacy advancement backgrounds use a `textures/` prefix and `.png` suffix. Minecraft 1.21 uses a direct asset identifier. Datagen keeps per-version Fabric registry signatures while reusing biome loot definitions and English fallback keys.
- Squid movement updates the internal swim vector used by vanilla and the entity velocity seen by the client. Ghast-like movement has a narrow adapter so Happy Ghast support does not fork the whole controller. The Wither bridge ignores the obsolete looting multiplier on versions where vanilla removed it. Untaming invokes vanilla side effects on component-era versions so wolf health returns to its wild maximum.
- Render adapters select the available shader, texture-binding, tick-delta, menu, and quad APIs. On 1.21.6 and later, custom quad passes bind projection and dynamic transforms explicitly. `Screen.renderWithTooltip` owns the background pass on 1.20.2 and later. A screen that draws its backdrop inside `render` suppresses the outer pass to avoid drawing it twice.
- The mixin processor relies on scoped suppressions for real deprecated or unchecked adapter calls. Preserve the 1.20.1 particle deserializer until the payload codec boundary. On the skin icon overwrite, Mixin's required `@author` and `@reason` tags stay at the annotation.
