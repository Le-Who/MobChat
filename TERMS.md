# Terms Notes for the MobChat CreatureChat Fork

This repository contains a local MobChat fork of CreatureChat. It is not the public upstream CreatureChat release and does not provide access to the upstream CreatureChat API, token shop, Discord support, or hosted services.

Use of this fork on a server is controlled by that server's operators. Operators are responsible for configuring the AI endpoint, API keys, moderation expectations, logs, backups, and player-facing notices.

This mod can send player and world context to the configured AI endpoint. Do not configure an endpoint unless you accept that provider's terms, privacy rules, pricing, and availability.

Minecraft, Mojang, Microsoft, OpenAI, and any configured AI providers are separate third parties. This fork is not endorsed by them.

Original CreatureChat source and asset licensing notices are retained where applicable. See `LICENSE.md`, `LICENSE-ASSETS.md`, and `REUSE.toml`.
